# 선지의 수학나라

경남고등학교 수학과 최선지 선생님이 만든 수학 활동을 한곳에 모은 웹 앱입니다. 활동은 게임, 탐험, 수행평가 같은 것들이에요.

- 선생님은 **교사 홈**에서 모든 활동을 한눈에 보고, 활동마다 기간과 모드(자유 도전·수업·수행평가)를 정해 엽니다.
- 학생은 선생님이 나눠 준 **활동 주소**로 들어와 학번·이름·비밀번호로 로그인하고 활동합니다.
- 결과는 **활동별 교사 현황판**에서 학년도별로 확인합니다.

## 활동 목록

| 활동 | 대상·단원 | 상태 |
| --- | --- | --- |
| 무리수 사냥: 경남이의 정글 탈출 | 중3 제곱근과 실수 | 운영 중 (`jungle-run.html`) — 공통 틀로 옮길 예정 |
| 보물을 찾아라 | 고1 도형의 방정식 | 구글 앱스 스크립트에서 운영 중 — 2027년에 옮길 예정 |
| 수박 만들기(합치기 게임) | 거듭제곱·동류항·단위분수 (후보) | 아이디어 |

## 주소

GitHub Pages 주소 형식: `https://<GitHub 계정>.github.io/<저장소 이름>/`

| 화면 | 주소(1단계 이후) |
| --- | --- |
| 학생 입구 | `/` |
| 교사 홈 | `/teacher/` |
| 활동 | `/activities/<활동 영문 이름>/` |
| 활동별 현황판 | `/activities/<활동 영문 이름>/teacher.html` |

※ 저장소 이름을 바꾸면 위 주소가 모두 바뀌고, 옛 주소는 자동으로 연결되지 않아요. 바꾼 뒤에는 학생에게 새 주소를 다시 안내해야 해요.

## 폴더 구조 (1단계 목표)

```
/
├─ index.html            학생 입구
├─ teacher/index.html    교사 홈(활동 모음)
├─ common/               공통 코드: 로그인, 저장, 운영 상태 확인, 공통 스타일
├─ activities/
│   └─ <활동 영문 이름>/ index.html(학생) · teacher.html(현황판) · img/
├─ prd.md                요구사항 명세서
├─ CLAUDE.md             AI 개발 원칙
├─ current_status.md     진행 상태
└─ README.md             이 파일
```

## 올리는 방법 (GitHub Desktop)

1. 바뀐 파일을 이 저장소 폴더 안의 같은 위치에 덮어씁니다.
2. GitHub Desktop 왼쪽에서 바뀐 파일을 확인하고, 아래 Summary 칸에 무엇을 바꿨는지 적은 뒤 **Commit to main**을 누릅니다.
3. 위쪽 **Push origin**을 누릅니다.
4. 1~2분 뒤 사이트 주소에서 새로고침(Ctrl+F5)해서 확인합니다.
